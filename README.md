# Quantum Teleportation

An implementation of the **Quantum Teleportation protocol** built with [Qiskit](https://github.com/Qiskit/qiskit).

## Overview
Quantum teleportation is a fundamental protocol in quantum information science that enables the transmission of an unknown quantum state (qubit) from one location to another using an entangled Bell state pair and classical communication channels.

## Requirements
- Python 3.8+
- [Qiskit](https://qiskit.org/)
- `qiskit-aer`
- `matplotlib`
- `jupyter` / JupyterLab

To install dependencies:
```bash
pip install qiskit qiskit-aer matplotlib notebook
```

## Running the Notebook
Launch Jupyter Notebook or JupyterLab:
```bash
jupyter notebook test.ipynb
```
